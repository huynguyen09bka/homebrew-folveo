# Homebrew tap for Folveo

[Folveo](https://folveo.app) — AI slide studio that runs on the AI subscription you already have (ChatGPT, Claude, Copilot) or free models. Pay once, no subscription.

```sh
brew install --cask huynguyen09bka/folveo/folveo
```

Updates: Folveo updates itself; `brew upgrade --cask folveo` also works.
